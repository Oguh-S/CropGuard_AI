# Free-tier deployment

The Render Blueprint deploys the React site as a free static site and Django/TensorFlow as a free web service. Supabase supplies the PostgreSQL database. This avoids a Google Cloud billing account. Free Render web services sleep after 15 minutes idle and have 512 MB RAM; TensorFlow may exceed that memory limit during model loading or prediction.

## 1. Create a Supabase database

Create a Supabase project on its Free plan, then copy its PostgreSQL connection string. Keep the URL private and include `sslmode=require`. The free database has 500 MB and may pause after a week of low activity.

## 2. Create the Render Blueprint

In Render, create a Blueprint from this repository and choose `render.yaml`. The Blueprint defines a free Docker web service for the API and a free static site for the frontend. Do not add a Render Postgres database; the API uses Supabase.

When Render asks for manual environment values, enter:

- `DATABASE_URL`: the Supabase PostgreSQL connection string.
- `DJANGO_ALLOWED_HOSTS`: the API hostname only, such as `cropguard-api.onrender.com` (no scheme).
- `CORS_ALLOWED_ORIGINS`: the frontend origin, such as `https://cropguard-frontend.onrender.com`.
- `CSRF_TRUSTED_ORIGINS`: the same frontend origin, including `https://`.
- `VITE_API_BASE_URL`: the API origin, such as `https://cropguard-api.onrender.com`, without `/api` or a trailing slash.

Render may assign different hostnames if those service names are already taken. Use the actual URLs shown in the dashboard. The frontend adds `/api` to `VITE_API_BASE_URL` automatically. `DJANGO_SECRET_KEY` is generated by the Blueprint.

The API container runs Django migrations at startup. Its health check uses `/api/`.

## 3. Check the deployment

Open `<API URL>/api/`; it should return JSON. Then open the static site, create an account, sign in, and submit a leaf photo. A free API service can take about a minute to wake after idle. If the API restarts or fails during prediction, inspect its Render logs for memory-limit errors; the free plan may not have enough RAM for this TensorFlow model.
